天気の自動取得と位置保存は初期状態オフ。説明を読んで設定を有効にすると、記録画面で自動取得します。設定は独立しており、天気だけ取得し正確な座標を保存しない利用ができます。手動の天気取得は設定オフでも、その都度通信内容を確認して実行できます。

1つの入力フォームで測位結果のPromise（非同期処理の結果）を共有し、成功・失敗を含めGPSを繰り返し起動しません。API再試行は同じ測位結果を使用します。リセット・保存後の別フォーム・同意撤回・日時指定に対して、旧応答が混入しないよう識別子と中断処理を使います。

APIに送るのは小数点以下2桁へ丸めた座標と気象取得の設定だけです。日記本文・写真・感情・正確なGPS座標を送信せず、APIの生レスポンスや問い合わせ座標も日記に保存しません。保存する出典情報は取得元・取得日時・対象日時・項目別の入力元・単位などです。

現在地は `locations.recording`（日記を記録した場所）に保存します。`locations.event`（出来事の場所）は自動設定せず、手入力または明示的な割り当てに限ります。過去の記録へ位置を自動補完しません。日時を手動指定すると自動天気を外し、手修正した項目は保持します。

## データ互換性

- DB名は `kioku-personal-v1`、DBバージョンは1、ストアは `entries` のまま。
- 既存記録の一括変換・削除・初期化はありません。本文・写真・感情・追記は保持。
- 記録のschemaVersionは1、バックアップ書き出しは形式2。追加は任意フィールドなので、旧記録に位置情報がなくても表示できます。
- バックアップ形式1・2を読み込め、未知フィールドも保持します。未対応形式・不正な位置や気象出典は安全に拒否します。
- 追加の位置・気象フィールドは形式2の検査値・復元後照合の対象です。
- 保存済みの場所を手動更新するときは、同じトランザクションで最新レコードを読んでから該当の場所だけを更新します。

計77グループに加え、公開前の静的検査が成功しました。失敗した途中実行はこの件数に含めません。

Windows上のChrome / Playwrightの一時ブラウザ環境とテスト専用DBを使用。API通信は固定の架空応答に置換し、測位はテスト内で生成した架空の値だけを返します。本番DB名はテスト側で遮断し、`watchPosition`による追跡も検出します。実際の天気APIへの通信や測位は行っていません。

確認した主な異常系：許可拒否・測位不能・タイムアウト、API失敗、遅い応答の保存後到着、手入力との競合、同意撤回、別タブの設定変更、場所削除後のGPS到着、不正な位置を含む復元、新モジュール欠損、途中の書き込み失敗。いずれも既存データを保持することを確認しました。

再実行にはNode.jsとPlaywrightを使用します。

```text
node tests/release-check.cjs
node tests/run.cjs
node tests/weather-location.cjs
node tests/update-safety.cjs
```

## 残る制約・未実施事項

- Ver.0.2のiPhone Safari／ホーム画面PWAでの実機確認は未実施。Ver.0.1.1での成功とは別に確認してください。[確認表](IPHONE-CHECKLIST.md)に模擬GPS/APIで行う項目を追記しました。
- 実際のOpen-Meteoへの通信と実GPSでの精度・応答時間は未検証です。仕様は公式文書を確認しましたが、自動テストは模擬APIを使用しています。
- 端末のGeolocation APIを利用し、GPSセンサー単独での測位を保証するものではありません。常時追跡はありません。
- 日時を手動指定した記録には現在の天気を付けません。過去・未来の天気を取りに行く機能や地図、地名の自動取得は未実装です。
- 同じフォームのGPSは失敗後も再起動しません。再測位には新しい記録を開始するか、場所の手入力を使います。
- 位置保存をオフにしても保存済みの日記の位置は削除しません。詳細で個別に変更・削除できます。過去に書き出したバックアップの内容は変わりません。
- バックアップは引き続き暗号化されていません。位置保存を有効にした場合は正確な位置も含むため、利用者が保存先を管理してください。
- 元からある容量制限・一部キャッシュ欠損の自動修復未対応などは維持されています。
- 前回作成したローカルのNetlifyパッケージはVer.0.1／Ver.0.1.1のままです。Ver.0.2の試験や配布に流用しません。
- 新版公開時はenvironment.jsを含めたアセット一式が必要です。今回は公開操作をしていません。
